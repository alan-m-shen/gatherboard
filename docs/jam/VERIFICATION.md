# 原生编辑器改造验证

此次修改已废弃独立编辑器及其 16 项 XML 测试；该测试数不适用于新版本。

实际浏览器检查（1280×720）：

1. 完整原生编辑器启动，Scratchpad（便笺本）、白板组件、通用图形、更多图形存在。
2. Kennedy 视图，100% 缩放，从底部拖便签到屏幕 (620,280)，对象左上约 (611,270)，在释放位置邻近网格处，无远距离跳动。
3. Kennedy 视图，50% 缩放，从底部拖矩形到 (490,230)，图形左上约 (493,233)，无缩放倍数造成的落点偏移。
4. 从画布把便签拖入原生 Scratchpad，出现缩略图。
5. 打开原生 Sketch 视图，Scratchpad 缩略图仍存在，拖回画布成功。
6. Sketch 视图，100% 从快捷栏拖矩形到 (750,250)，图形左上约 (750,255)。
7. Sketch 视图，50% 缩放后滚动画布，再拖圆形到 (820,260)，对象左上约 (812,254)，无滚动偏移造成的远距离跳动。
8. Sketch 最终入口控制台无新错误；最初插件加载次序错误已经修正，在 App 构造前建立官方插件队列。

上述误差含原生 drag preview 锚点、网格吸附和选择框外扩。预期是原生预览对应网格落点，不是强行把鼠标点设为几何中心。

仍待验证：移动端真机、极端缩放、跨浏览器、复杂自定义 stencil、原生文件工作流回归。文件保存现在调用原生 action；不再使用首版自行实现的 XML 导入限制或浏览器草稿存储逻辑。
